# StudentManager — консольное приложение для учёта студентов и оценок

Лабораторная работа 2
Приложение хранит студентов и их оценки, считает средние баллы, сортирует и
фильтрует список, читает и пишет CSV, экспортирует ТОП-N студентов.

## Структура проекта

```
project_root/
  lab/
    __init__.py
    errors.py       # собственные исключения
    models.py       # класс Student (id, name, grades, average)
    processing.py   # добавление/удаление/обновление, сортировка, фильтрация, статистика
    io_utils.py     # чтение/запись CSV, экспорт ТОП-N
    main.py         # консольное меню (точка входа)
  data/
    students.csv    # пример входного файла
  tests/            # автотесты pytest
  pytest.ini
  requirements-dev.txt
  README.md
  REPORT.pdf        # отчёт
```

## Запуск

Из корня проекта (папки `project_root`):

```
python -m lab.main
```

Меню:

| Пункт | Действие |
|---|---|
| 1 | Загрузить из CSV (Enter — файл `data/students.csv`) |
| 2 | Сохранить в CSV |
| 3 | Показать всех студентов |
| 4 | Добавить студента |
| 5 | Удалить студента по ID |
| 6 | Обновить оценки по ID |
| 7 | Статистика по группе |
| 8 | Экспорт ТОП-N в CSV |
| 9 | Сортировка (avg / name / id) |
| 10 | Фильтрация (по фрагменту ФИО и диапазону среднего балла) |
| 0 | Выход |

Оценки вводятся через запятую: `80, 90, 100`. Пропуск — пустая часть: `80, , 100`.

## Формат CSV

```
id,name,grade1,grade2,grade3
1,Иванов Иван,78,85,90
4,Иванов Олег,100,90,
```

- обязательные колонки: `id`, `name`; далее любое количество колонок с оценками;
- оценки — целые числа от 0 до 100, пустая ячейка — отсутствующая оценка;
- заголовок необязателен, кодировка — UTF-8 (BOM допускается).

При сохранении число колонок с оценками выравнивается по самому длинному списку.
Экспорт ТОП-N создаёт файл с колонками `id,name,average,grades` (оценки через пробел).

## Обработка ошибок

Все ожидаемые ошибки (плохой CSV, нет файла, нет прав, дубликат ID, студент не найден,
неверный ввод) — это наследники `StudentManagerError`. Меню их перехватывает и печатает
сообщение вида `Ошибка: ...`, программа при этом не завершается.
